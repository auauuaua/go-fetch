# go fetch
## De-digital horror-ify your life: hands on  physical method for accessing digital media
...and software to make viewing it suck less

## A system for easily pulling up your favorite photo albums, music playlists, etc, without ever touching a computer or phone.

The hardware and companion Windows software allows you to link a QR code to any file/website/etc.

The hardware accepts a standard poker sized card with the QR code on the back, so it feels more like putting in a CD than scanning a code.

The software allows easy setup of the card layout so you can get them printed, or print on cardstock yourself.

It's customizable to launch any file or link from any QR code with any program, and allows you send program specific commands to the program through a IR remote.

1. go fetch Card Player - Windows PC Editor and Launcher

2. go fetch Card Player Arduino - Arduino code for the hardware

3. go fetch Card Player Hardware - CAD Files, Schematics, etc.
